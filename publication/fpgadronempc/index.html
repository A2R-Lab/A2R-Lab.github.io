End-to-End Hardware-Algorithm Co-Design for High-Rate FPGA-Accelerated Model Predictive Control on Tiny Drones

Andrea Grillo , Brian Plancher
May 2026
PDF Workshop Website

Abstract

Model Predictive Control (MPC) enables highperformance feedback control by explicitly handling system dynamics and constraints but is often computationally prohibitive for resource-constrained robots. We overcome this challenge via an end-to-end co-design approach that jointly optimizes the solver algorithm, hardware architecture, and physical integration. Our system features a solver based on the alternating direction method of multipliers (ADMM) framework, tailored for FPGA implementation using reduced-precision arithmetic, paired with a custom-designed lightweight, 6g PCB to ensure high-bandwidth communication for deployment on a 35g Crazyflie quadrotor. This tight hardware-algorithm integration enables 500 Hz constrained control over long horizons, a regime previously unattainable. Hardware experiments demonstrate up to 16× faster solve times and a 244× improvement in energydelay product over state-of-the-art, embedded, microcontrollerbased solvers, proving that co-design is essential for sophisticated constrained control on highly compute-limited platforms.
